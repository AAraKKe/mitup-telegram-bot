# Mitup - The Telegram Bot to organize with friends

![mitup_logo](/docs/assets/images/mitup_logo.jpg)

[The Mitup Telegram Bot](https://staging.mitup.social/usage/getting_started/) allows Telegram users to create meetings and send them to friends through private chats or Telegram groups.

## Contribute
Mitup is built in Python leveraging the [python-telegram-bot library](https://python-telegram-bot.org/). If you are confortable coding in python, checkout the [Contribution Guide](https://staging.mitup.social/collaborate/).
