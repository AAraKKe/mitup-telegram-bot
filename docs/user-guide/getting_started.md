# Getting started

Mitup runs entirely as a private conversation with you. Unlike other bots, it doesn't need to be added to your group and asks for no permissions of its own.

Open [@mitupbot](https://t.me/mitupbot?start=src_web) and tap Start to begin the chat. Mitup asks for your timezone, and once that's set the main menu appears.

## The language is picked for you

Mitup reads the language your Telegram client is set to and speaks it from the first message, when it's one of the languages Mitup has been translated into. Otherwise it starts in English. Either way you can change it later under *⚙️ Settings*{.button-like}.

## Set your timezone

The first message asks where you are.

Two ways to answer it:

1. Send your city name
2. Share your location via Telegram

Mitup needs this because meetings have dates and times, and reminders go out on your clock. With everyone's timezone set, a meeting reads correctly for each person who sees it, wherever they are.

!!! note "Privacy notice"

    We don't store the location you send during timezone setup. We use it only to look up your
    timezone, then discard the location. See the [Privacy page](../faq/privacy.md) for details on
    what Mitup stores.

Once it's set you land on [the main menu](main_menu.md).
