# Contributing to Mitup

First off, thank you for considering contributing to Mitup! 🎉 We appreciate you taking the time to help improve the project.

There are many ways to contribute, from reporting bugs and suggesting features to writing code and improving documentation. All contributions are welcome!

To ensure a smooth process, we have detailed contribution guidelines available in our documentation:

*   **🛠️ [Setup Guide (Required for Code)](docs/collaborate/code-contributor.md):** How to set up your local development environment.
*   **📚 [Main Contribution Hub (in Docs)](docs/collaborate/commiting-to-repo.md):** This is the best place to start. It covers the entire process for contributing code, including setting up your environment, our development workflow, and coding standards.
*   **✨ [Other Ways to Contribute (Supporter Guide)](docs/collaborate/supporter.md):** Learn about non-code contributions like translation, donation, and more.
*   **📜 [Code of Conduct](docs/collaborate/code_of_conduct.md):** Please read this to understand our community standards and expectations.
*   **🛠️ [Local Validation Guide](docs/collaborate/local-validation.md):** Learn how to run formatting, linting, type-checking, and tests locally.

## Reporting Issues

If you encounter a bug or have an idea for a new feature, please check the [existing issues](https://gitlab.com/meetupbot/mitup-telegram-bot/-/issues) first. If you don't find a similar one, feel free to [open a new issue](https://gitlab.com/meetupbot/mitup-telegram-bot/-/issues/new/choose) using the appropriate template.

We look forward to your contributions! 😊
